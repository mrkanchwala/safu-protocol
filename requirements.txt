# SAFU backend — pinned runtime dependencies

# Added 2026-08-17 (post-7a audit remediation). Before this the repository had
# NO requirements file, lockfile, pyproject or setup.py of any kind, so:
#   * dependency resolution was not reproducible between this host and the VPS,
#   * `pip-audit` could only scan whatever happened to be in the ambient
#     interpreter rather than the project's actual dependency set, and
#   * the Rust side was fully pinned via Cargo.lock while the Python side that
#     signs claim approvals and talks to the oracle KMS was not pinned at all.
#
# Versions below are the ones the 7a audit was actually executed and verified
# against (24/24 tests green on this set) — captured from the working
# interpreter, not chosen from latest-on-PyPI.
#
# DERIVED from real imports across api/, safu/ and scripts/, not from
# `pip freeze` (which would bake in every unrelated package on the machine).
#
# Exact pins (==) rather than ranges: this service signs payout approvals, so a
# silent transitive upgrade is not an acceptable failure mode. Bump
# deliberately, re-run the suite, and record it.
